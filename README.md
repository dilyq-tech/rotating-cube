# Вращающийся 3D-куб на Pygame

3D-рендерер, написанный с нуля без готовых 3D-библиотек.

## Что внутри
- Матрицы поворота вокруг осей X и Y
- Перспективная проекция 3D → 2D
- Алгоритм художника (сортировка граней по глубине)
- Отрисовка граней и рёбер в Pygame

## Запуск
pip install pygame
python3 cube_pygame.py
